#  WestEndCafe

WestEndCafe is a web-based food ordering and reservation system built with **Django** and **Bootstrap 5**.  
It allows customers to browse the menu, place online orders, and make reservations seamlessly through an interactive and responsive interface.

---

## Features

- **Online Ordering System** – Users can add food items to their cart and place orders.
- **Table Booking** – Customers can book tables for specific dates and times.
- **Admin Dashboard** – Manage menu items, view orders, and handle reservations.
- **Order Management** – Track order status (Pending, Preparing, Completed).
- **Responsive Design** – Built with Bootstrap 5 for mobile-friendly use.
- **User Authentication** – Register, login, and manage user profiles securely.

## Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, Bootstrap 5
- **Database:** SQLite (default)
- **Version Control:** Git & GitHub
